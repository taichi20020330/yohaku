# yohaku

本を読みながら、引用・問い・感想をすばやくメモし、それらを線でつないで自分の思想を育てるための思考拡張アプリ。

## 使い方

`index.html` をブラウザで開くだけで動きます（ビルド不要）。

| 入力 | 意味 |
|---|---|
| `#書名 / 著者` | 読む本を切り替える |
| `23 本文` | 23ページの引用 |
| `?本文` | 問い |
| `!本文` | 感想 |
| `@本文` | 次に読む本・参考文献 |
| `Tab` | メモの種類を切り替える |
| `Esc` | つなぎ先の選択を外す |

- メモをクリックして選んだ状態で新しいメモを保存すると、そのメモに自動でつながります。
- Shift+クリックで、選択中のメモと別のメモをつなぎます。
- トラックパッドの2本指スワイプで移動、ピンチ（または ⌘/Ctrl＋スクロール）で拡大縮小します。

## データの形

すべてのメモは1つのグラフとして扱い、プロジェクトはその上の「重なってもよい名札」です。

- `nodes`：メモと本。`projects`（所属するプロジェクトのid）と `pos`（プロジェクトごとの画面位置）を持つ
- `edges`：2つのメモをつなぐ無向の線。プロジェクトをまたいでよい
- `projects`：プロジェクト名と、読書中の本・ページなどの状態

プロジェクトを開くと、そのプロジェクトのメモと、外のプロジェクトへの「入口」が表示されます。入口をクリックすると、そのプロジェクトが同じ画面の中に広がります。すべて広げると、全体が1つの網目として現れます。

## 保存先

- claude.ai のアーティファクトとして開いたとき：アーティファクトのデータベースに保存されます（端末をまたいで同期）。
- GitHub Pages など claude.ai の外で開いたとき：Googleでログインすると Firebase（Firestore）に保存されます。データは `users/{uid}/nodes`・`edges`・`projects` に置かれ、`firestore.rules` により本人しか読み書きできません。オフラインでも書け、通信が戻ると同期されます。
- ログインしていないとき：サンプル入りの「お試しモード」で開きます。自由に書き込めますが、どこにも保存されず、ページを閉じると元に戻ります。

### Firebase の設定

`index.html` の `FIREBASE_CONFIG` に、Firebase コンソールの「プロジェクトの設定 → マイアプリ（ウェブ）」に表示される値を入れます（公開しても問題のない値です）。Firestore の「ルール」には `firestore.rules` の内容を貼ります。
